# AGENTS.md — руководство для контрибьюторов lm-agent

## О проекте

`lm-agent` — Java-консольное приложение для взаимодействия с LLM-моделями через OpenAI-совместимый API. Позволяет отправлять промпты, сохранять сгенерированный код, применять SEARCH/REPLACE-патчи и вести историю ответов в Git.

## Структура проекта

```
src/
  main/java/ru/asmisloff/        # исходный код
    command/                      # реализация команд (find, preview, save-code, send-prompt, ...)
    tool/                         # инструменты для вызова моделью (Tool, ToolRegistry, SaveToFileTool, ...)
  main/resources/                 # ресурсы (default-system-prompt.md, log4j2.xml)
  test/java/ru/asmisloff/         # тесты (на каждый класс — свой *Test)
lm-agent.yml                      # конфигурация приложения (API-ключ, модель, промпты, алиасы)
prompt.md                         # файл промпта по умолчанию
ans.md                            # файл для ответа модели по умолчанию
agent.bat                         # запуск fat JAR
```

## Команды сборки, тестирования и разработки

| Команда | Назначение |
|---|---|
| `mvn compile` | Компиляция |
| `mvn test` | Запуск всех тестов (JUnit 5 + Mockito) |
| `mvn package` | Сборка fat JAR (`target/lm-agent-1.0-SNAPSHOT-jar-with-dependencies.jar`) |
| `mvn clean` | Очистка `target/` |

Запуск приложения: `agent.bat <команда> [аргументы]` (или напрямую `java -jar target/lm-agent-1.0-SNAPSHOT-jar-with-dependencies.jar <команда> [аргументы]`).

## Стиль кода и правила именования

- **Java 17** — используются современные фичи (`var`, `switch`-expressions, текстовые блоки где уместно).
- **Кодировка** исходников — UTF-8.
- **Отступы** — 4 пробела.
- **Именование**: классы `PascalCase`, методы/переменные `camelCase`, константы `UPPER_SNAKE_CASE`.
- **JavaDoc** — на русском языке, лаконичный. Аннотируйте публичные методы.
- **Lombok** — активно используется (`@Log4j2`, `@UtilityClass`, геттеры/сеттеры при необходимости).
- **Тесты**: на каждый продакшн-класс — отдельный `*Test`-класс в том же пакете `ru.asmisloff`. Имена тестовых методов — `snake_case` с описанием сценария. Используйте `@DisplayName` с русским описанием.

## Рекомендации по VCS

### Коммиты

Формат: `KNI-XX: краткое описание`, где `KNI-XX` — номер задачи в трекере. Описание на русском, в нижнем регистре после двоеточия. Примеры:
```
KNI-60: чтение патчей из Git
KNI-54: save-code в виде инструмента
```

### Pull Request'ы

- Привязка к задаче через префикс в названии ветки/коммитах.
- Описание PR должно включать: что сделано, зачем, как тестировалось.
- Убедитесь, что `mvn test` проходит без ошибок.

## Конфигурация

Файл `lm-agent.yml` — основной конфиг. Ключевые секции:
- `base-url`, `model`, `api-key` — подключение к API.
- `prompt-filename`, `answer-filename` — файлы ввода/вывода по умолчанию.
- `model-aliases` — короткие имена для моделей.
- `system-prompts` — именованные системные промпты (`code`, `patch`, `check`).
